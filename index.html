03. Featured Projects

Cobot + Vision

Vision-Guided Pick & Place

Generalised Cobot Automation · IIT Tirupati

Took over a fragile pick-and-place setup where RViz showed one path while the robot executed another, with frame and tool errors and inconsistent accuracy. Rebuilt it into a generalised, coordinate-free system on a JAKA ZU5 cobot with an OnRobot 2FG7 gripper, guided by a ZED 2i depth camera. Optimised path planning makes the planned path the executed path, and three calibration cycles brought it to ~97% accuracy and safety with zero hardware damage.

9-Stage Pipeline

  1. Home
  2. Approach via ZED 2i
  3. Error correction & sizing
  4. Gentle grasp
  5. Pick
  6. Optimised path
  7. Safe move
  8. Place without crushing
  9. Return home
ROS2 Humble Python C++ ZED 2i Motion Planning Calibration
